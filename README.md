## 📌 What is NovxX?

NovxX is a full-stack EV intelligence platform targeting emerging markets where smart EV tools don't exist yet. It gives EV users data-driven insights to maximize battery performance, understand their driving habits, and make smarter decisions.

Built solo, from scratch, by a self-taught developer from Tank, KPK, Pakistan — connected to real EV engineering study.

## ⚙️ Local Setup

### 1. Clone the repo

```bash
git clone https://github.com/Umair-Ali369/novxx.git
cd novxx
```

### 2. Install frontend dependencies

```bash
npm install
```

### 3. Install backend dependencies

```bash
cd server
npm install
```

### 4. Environment variables

Create `server/.env`:

```env
MONGO_URI=your_mongodb_connection_string
JWT_SECRET=your_jwt_secret
GROQ_API_KEY=your_groq_api_key
PORT=9000
```

Create `.env` in root (frontend):

```env
VITE_API_URL=http://localhost:9000/ev/api
```

### 5. Run locally

```bash
# Terminal 1 — Backend
cd server
node server.js

# Terminal 2 — Frontend
npm run dev
```

Frontend runs on `http://localhost:5173`  
Backend runs on `http://localhost:9000`

## 🤖 AI Features

NovxX uses the **Groq SDK** with the `qwen/qwen3.8-27b` model for:

- **AI Insight Engine** — 3 personalized insights after every battery calculation
- **Weekly AI Summary** — Analyzes your last 10 trips and generates a performance summary with actionable tips

Both features require a valid Groq API key. Get one free at [console.groq.com](https://console.groq.com).
