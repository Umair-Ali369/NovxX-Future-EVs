### Backend

**`aiInsightController.js`:**
- Two endpoints: `generateAIInsights` and `generateWeeklySummary`
- Uses `groq-sdk` with model `llama-3.1-8b-instant`
- `generateAIInsights`: receives calculation data, builds contextual prompt, returns 3 specific one-sentence insights
- `generateWeeklySummary`: receives array of calculations, computes averages, returns 3-sentence personalized weekly coaching summary
- Prompt rules: specific to actual data, no numbering, no bullets, plain sentences separated by newlines
- Response parsed by splitting on newlines and filtering empty lines

**`aiRoutes.js`:**
- `POST /ev/api/ai/insights` — protected route
- `POST /ev/api/ai/weekly-summary` — protected route
- Both routes use `authMiddleware`

**Registration in `server.js`:**
```js
const aiRoutes = require("./Routes/aiRoutes")
app.use("/ev/api/ai", aiRoutes)
```

### Frontend

**`AIContext.jsx`:**
- `generateInsights(calculationData)` — POST to `/ev/api/ai/insights`
- `generateWeekly(calculations)` — POST to `/ev/api/ai/weekly-summary`
- Both wrapped in `useCallback` to prevent function recreation on every render
- `aiInsights`, `weeklySummary`, `aiLoading`, `aiError` exposed in context
- `clearAI()` resets all state
- Rate limit error (429) handled separately with specific message

**`AIInsightPanel.jsx`:**
- Auto-generates insights when `calculationData` prop arrives
- `useRef(false)` guard — prevents multiple API calls per calculation
- `useState(false)` initiated flag — prevents blank flash before loading starts
- Three states: loading (skeleton), error (red border), success (insights list)
- Each insight shown with `✦` accent bullet
- "Llama 3.1" badge in top right

**`ShareCard.jsx` update:**
- Now reads `aiInsights` from `AIContext` via `useAI()`
- Shows first 2 AI insights inside the share card
- AI insights included in "Copy Results" clipboard text
- `max-h-[90vh] overflow-y-auto` added to handle longer cards on mobile

**Wiring in `Calculator.jsx`:**
```jsx
{EVresult && (
  <AIInsightPanel
    calculationData={{
      range: EVresult.data.range,
      efficiency: EVresult.data.efficiency,
      batteryUsage: EVresult.data.batteryUsage,
      batteryStress: EVresult.data.batteryStress,
      energyConsumption: EVresult.data.energyConsumption,
      drivingCondition,
      drivingStyle,
      temperature,
      terrainType,
      acUsage,
      passengers,
      vehicleLoad,
    }}
  />
)}
```

**`main.jsx` provider order:**
